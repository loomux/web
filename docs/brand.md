# Loomux brand

The Loomux identity (LOOM-176): what the logo is, how to use it, and where
its files come from. It sits on top of the client's design tokens
(`src/styles/tokens.css`) and the redesign principles
(`docs/design/redesign/principles.md`); it adds one token and no fonts.

## The idea

Loomux is loom plus tmux: it carries your requests to coding agents and
weaves their work back into one conversation. The logo is the name written
as **one kingfisher thread**, l through x without lifting, and the x is
crossed by a second, golden thread: the **weft**, the first stitch. The
weft is the only accent. Everything else in the mark stays quiet so it
reads first.

The app icon reduces the wordmark to an **lx** monogram on a kingfisher-mist
tile.

## Files

Everything is generated by [`brand/generate.py`](brand/generate.py) from
one set of path data. Change the geometry there, run it, and commit the
outputs; never edit an output by hand.

```sh
python3 docs/brand/generate.py   # needs rsvg-convert (librsvg) and ImageMagick
```

The SVGs and `brandPaths.ts` are plain text and come out the same
anywhere. The PNG and .ico bytes depend on the rasteriser, so re-running
with other versions can change them without any visible difference. The
committed files were made with:

| Tool | Version |
|---|---|
| rsvg-convert (librsvg) | 2.63.2 (cairo 1.18.6) |
| ImageMagick | 7.1.2-32 Q16-HDRI |
| Python | 3.14.7 (any 3.9+ works) |

`src/ui/brandPaths.test.ts` runs `generate.py --paths` and fails if the
committed `brandPaths.ts` doesn't match the generator.

| File | Use |

| `docs/brand/wordmark-small-light.svg`, `-dark.svg` | The small cut, under 24 px tall |
| `docs/brand/mark-light.svg`, `-dark.svg` | The lx monogram without a tile |

| `public/favicon.ico` | 16 and 32 px, for browsers that ask for `/favicon.ico` |

In the client, use the components, never an image: `<Wordmark height={…} />`
and `<BrandTile />` take their colours from the tokens, so they follow the
theme.

## Colour

| Part | Light | Dark | Token |
|---|---|---|---|
| Thread | `#0a737e` kingfisher | `#43bac5` | `--accent` |
| Weft (the x's crossing) | `#b06f00` deep marigold | `#f5b23a` marigold | `--mari-deep` |
| Icon tile | `#dceff0` kingfisher mist | `#0f313a` in-app | `--accent-soft` |

Contrast, as graphics (WCAG 1.4.11, needs 3:1):

| Pair | Ratio |
|---|---|
| Thread `#0a737e` on porcelain `#e9eef3` / tile `#dceff0` | 4.78 / 4.69 |
| Weft `#b06f00` on porcelain / tile | 3.51 / 3.45 |
| Thread `#43bac5` on night `#0c1426` / surface `#132036` | 7.93 / 7.04 |
| Weft `#f5b23a` on night / surface | 9.89 / 8.79 |

Marigold `#efa10c` is only 1.84:1 on porcelain, which is why the light
weft is the deeper `#b06f00`. `--mari-deep` is a brand colour only: the
app's "needs you" signal stays `--mari` with its diamond.

The installed app icon always uses the light tile, whatever the theme: a
launcher has no theme to follow. On a dark surface it stays legible
because the tile carries its own ground.

## Geometry

- **Stroke:** monoline, round caps and round joins, 5 units on the
  wordmark's 68-unit height (5 on the mark's 64-unit grid).
- **Smooth turns:** every change of direction is tangent-continuous (each
  curve leaves along the line it arrived on), so no turn is a corner.
  Where a stroke goes back over itself (the m and u stems) the round cap
  rounds it.
- **The o's** are smaller than the other letters' bowls (radius 11.5,
  sitting on the baseline, tops level with the m's arch) and joined by a
  short tie at shoulder height. The tie is a quiet hint of the loop; it
  must never compete with the weft.
- **Small cut:** below 24 px tall the tie fuses the o's into one blob, so
  `wordmark-small-*` drops it, opens the gap between the o's by 2 units
  and uses a 5.6-unit stroke. `Wordmark` switches automatically.
- **Icons at 32 px and under** use a 6.5-unit stroke (`public/icon.svg`,
  `favicon.ico`, `BrandTile`).

## Using it

- **Minimum size:** wordmark 24 px tall (small cut down to 14 px); icon 16 px.
- **Clear space:** at least the wordmark's x-height (about 40% of its
  height) on every side; for the icon, a quarter of its width.
- **Lockup:** tile, then wordmark at 70% of the tile's height, with a gap
  of a third of the tile. The sidebar uses a 32 px tile and a 22 px
  wordmark.
- **On photos or busy grounds:** don't. Put it on porcelain, night or a
  surface token.
- **Monochrome:** where one colour is required (notification icons,
  embossing), both threads take that colour; the crossing still reads.

Don't:

- recolour the thread, or make the weft anything but marigold;
- add a gradient, glow, outline or shadow;
- set "loomux" in a font instead of using the drawn wordmark;
- stretch, slant or rotate it, or change the stroke weight;
- enlarge the tie between the o's or bring back the arch over them;
- use the weft colour, or the diamond, as decoration elsewhere in the UI.

## Typography

No brand font. The UI and headings stay in Atkinson Hyperlegible Next and
code in Atkinson Hyperlegible Mono, self-hosted (`@fontsource`). The
wordmark is drawn, so it needs no font. The README banner's tagline names
Atkinson Hyperlegible Next with system fallbacks.

## Lookalike check

Script monograms are common in personal and craft brands. We checked this
lx and the one-thread wordmark by eye against well-known marks and found
nothing close. That was not a trademark search.
