### Added

- Settings lists the devices signed in to Loomux (this one first, then by when each was last used), with
  "Log out this device" for the others: a lost phone, an old laptop.

### Changed

- The credentials page is now the Vault. It does the same things with clearer wording: add a credential (its
  value is typed once into a password field, then cleared and never shown), replace a value, or delete one after
  confirming. Scopes read "Every workspace and agent", "Only in ledger-api", "For claude-code only". Saving shows
  its progress.
- The web client's version panel in Settings matches the new design.
